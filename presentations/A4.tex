\section{Introduction and Research}

LeanCoP inspired a large family of provers which, with a small amount of modifications, could improve the performance of the connection prover in a large set of problems\cite{Otten2023leanCoP20}.
The ones that inspired this work change one property of the original LeanCoP at the initial time.

LeanCoP 2.0\cite{ottenLeanCoP20} added several options, most notably \atom{cut} and \atom{scut} to restrict backtracking in connection calculus.
That version also enables \emph{iterative deepening} with \atom{comp(J)}, which iteratively limits the height 1 at a time of the tree when the prover is saturated\footnotemark{} until it reaches maximum height \atom{J}.
Afterwards it restarts iterative deepening from 1, but without any other option active.
