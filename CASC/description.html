SATResetCoP 1.0

Martin Fixman
University of Cambridge, United Kingdom

Architecture

SATResetCoP is a connection prover for untyped first-order formulas without equality that is combined with a SAT solver to find unsatisfiability on the propositional formulas genrated by the set of grounded statements. It also uses properties of the SAT solver to guide the tree search by choosing the most convenient path to build the tree, while also resetting aggressively to increase the probability that the SAT solver would be saturated. This is inspired by SATCoP, developed by Rawson and Reger [RR21], specially by the "Future work" section of that paper which introduces ways to guide the connection prover based on properties of the SAT solver.

Strategies

SATResetCoP resets the entire tree rather than backtracking; this causes it to get a larger and more varied set of propositional clauses to the solver, thus making it more probably that it will contain an unsatisfiable subset of clauses. The size of the maximum tree in the connection prover grows a maximum of one at a time, as in LeanCoP 2.0 [O23]. This prevents unnecessarily long branches on simple problems, while also increasing the variety of propositional clauses added in the SAT solevrs. The objective is to control the tree to ensure saturation of the underlying SAT prover rather than relying in enhanced semantics based on LeanCoP.

Implementation

SATResetCoP is fully implemented in Python using a fork of the Connections Library [R23], which provides a general framework for the creationg and testing of connection provers. This fork adds a new calculus based on classical calculus that has the capacity to include LeanCoP-style cuts, and most importantly to define different strategies for different provers. These changes are currently being backported to newer versions of the library. The connections prover can run with a variety of SAT solvers and its results are mostly agnostic to this decision. No other Python library is needed. The final version can be downloaded from Github.

Expected Competition Performance

This is the first version of SATResetCoP, so I do not expect it to be very competitive in the general FOF category against mature saturation provers such as Vampire. However, I do expect it to have a strong performance against other connection provers, specially in problems that can easily generate an unsatisfiable set of propositional clauses. According to my experiments, it should be specially strong in the TPTP categories SWV, GEO, SWC, and NUM.
